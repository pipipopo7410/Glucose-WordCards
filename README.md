# 血糖調節：概念圖練習 2.0（測試版）

此包從使用者提供的血糖調節 1.0 `index.html` 衍生，保留自由擺放器官、連線、營養物質、胰島素、升糖素與細胞呼吸示意等核心教學活動，改寫為無需 CDN 的靜態網站。原 1.0 正式站不需更動。

## 上傳 GitHub Pages

1. 建立新的公開儲存庫，例如 `ipad-test-sugar-v2`。**不要覆蓋 1.0**。
2. 解壓 ZIP 後，將根目錄內所有檔案及 `icons/` 目錄一次上傳至新 repo 的根目錄（不是直接上傳 ZIP）。
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
4. 透過 `https://你的帳號.github.io/ipad-test-sugar-v2/` 開啟網站測試。
5. iPad/iPhone Safari → 分享 → 加入主畫面；Android Chrome → 安裝或加入主畫面。

## 操作說明

- **器官卡**：從左欄拖曳到畫布；放上後可自由移動，拖回左欄才回收，相關連線一併移除。點兩張器官建立有方向的箭頭；同方向再點一次移除。反方向可另建一條箭頭。
- **物質卡**：可重複使用的模板；將它放入器官右下物質框。已放置物質可拖出再放到別處、或拖到空白區移除。
- **激素卡**：可重複使用的模板；放入箭頭中間的虛線框，拔出後可移放別條。**肝臟↔血管的兩條反向連線可分別顯示胰島素和升糖素**，不再互相刪除。
- **即時提示**：預設關閉，表示允許先自行探索再檢查；開啟後，已知不合理的物質器官組合、激素路徑立即拒絕。提示不直接揭露必要路徑答案。
- **貼齊格線**：預設關閉；開啟時會立刻依學生目前位置就近對齊，之後每次移動都會就近吸附、避免重疊，不自動產生標準概念圖。
- **細胞呼吸示意**：細胞粒線體框中放入葡萄糖後，將氧氣拖到同一字卡觸發水、二氧化碳、ATP 動畫。這是物質利用的簡化示意，不表示胰島素直接作用於粒線體。
- 也可先點選物質／激素，再點目標槽；器官則可先選卡再點畫布，作為拖曳的備用操作。

## 通關與教學取捨

**五條必要路徑**：

- 口腔 → 小腸（口腔：澱粉；小腸：葡萄糖）
- 小腸 → 血管（小腸與血管：葡萄糖）
- 血管 → 肝臟（胰島素；血管：葡萄糖；肝臟：肝糖）
- 肝臟 → 血管（升糖素；肝臟：肝糖；血管：葡萄糖）
- 血管 → 肌肉組織（胰島素；血管：葡萄糖；肌肉：肝糖）

**兩條選做路徑**：血管→脂肪組織、血管→細胞粒線體。無須完成即可過關；若選做並畫出不正確內容，仍會標示供修正。不能「任取五條有分數的連線」就通關。

> 教學簡化：胰島素促進肝糖合成及影響全身血糖調節，不能解讀成胰島素直接將葡萄糖『搬進』粒線體。畫面只呈現高中前的主要趨勢，並非生理定量模型；胰島素與升糖素的作用可同時存在，圖像是便於比較的示意。

## 離線與入口網

本單元提供 `manifest.webmanifest`、`sw.js` 及本機 Icon，可獨立安裝；第一次連網完整快取後應具備獨立離線使用條件，**仍需要在實機驗證**。

要在「剛剛數位小教室」入口網整包離線安裝，未來需把整個單元部署到入口網同來源的子目錄（如 `Bio-Class/units/sugar/`），更新入口網快取清單並完成跨頁離線測試。`unit.json` 是為這個整合預留的單元資訊；單純在入口新增另一個 GitHub Pages 網址不等於已能整包離線。
