# 血糖調節 3.1｜完整 GitHub Pages 安裝版

解壓縮後把**所有檔案與 icons 資料夾**上傳到獨立 GitHub Pages 儲存庫根目錄，啟用 Settings → Pages → Deploy from a branch → main → /(root)。

- 血糖的五條核心路徑仍為必要；脂肪組織與細胞利用葡萄糖屬選做。
- 肝臟→血管上有兩個可獨立操作的激素位置：**升糖素必答**、**腎上腺素選做**。後者不會因缺漏而擋住動畫解鎖。
- 完成核心概念圖並按「檢查架構」後，畫布右上角出現「吃飯／運動」兩個演示按鈕，可暫停、重播、結束。動畫取用學生實際排列位置，結束後不改動答案。
- 飯後動畫中的口腔澱粉「變到消失」表示**此段示意物質已從口腔轉移**，不是說真實消化瞬間完成。小腸仍保留澱粉／葡萄糖並存的簡化。
- 運動動畫呈現的是**假設長時間能量消耗且血糖下降過多的情境**；一般正常運動不等於一定發生低血糖。肌肉的肝糖（肌糖原）用於肌肉自身，不直接釋放血糖；肝臟肝糖可分解為葡萄糖幫助維持血糖。腎上腺素也是血糖調控的補充調節訊號。
- 動畫以**相對大小**表示物質量趨勢，並非實際血糖值、數量守恆模擬或病理預測模型。
- iPad／iPhone：Safari 開啟 Pages → 分享 → 加入主畫面；Android Chrome：安裝應用程式。先連網完整載入後再測試離線功能。
- 大入口整合時，請把**整個單元資料夾**放到入口網站 Service Worker 可控管的同一範圍內，並更新快取 manifest；僅用跨儲存庫外部連結不能保證整包離線。

詳細測試記錄見 TESTING.md。原本 3.0 及 1.0 不需修改。
