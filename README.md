# 血糖調節 3.0｜GitHub Pages 完整上傳包

## 安裝／測試
1. 建立新公開 GitHub 儲存庫，例如 `ipad-test-sugar-v3`（保留舊版則不要覆蓋舊庫）；將本資料夾 **內容** 上傳根目錄。
2. Settings → Pages → Deploy from a branch → `main` / `(root)`。
3. 以 Safari 在 iPad/iPhone 開啟網站 → 分享 → 加入主畫面；Android 在 Chrome 選「安裝應用程式」。
4. 等待離線狀態顯示已就緒，再以飛航模式重新啟動實機驗收。

## 操作
- 先排列器官，點兩張器官建立有方向的連線。
- 放物質於器官旁的儲存槽；若需激素，放在線段中央橢圓框。
- 口腔→小腸、小腸→血管：**沒有激素框**，是正常的。
- 小腸放澱粉或葡萄糖都顯示「澱粉/葡萄糖」；血管顯示「葡萄糖 (血糖)」。
- 五條必要路徑都正確後，按「檢查架構」解鎖吃飯／運動演示。
- 演示沿學生自行安排的位置播放，支援暫停、繼續、重播、結束；當前播放期間暫時避免拖動字卡。
- 即時提示預設關閉；貼齊格線預設關閉。脂肪組織及細胞利用葡萄糖為選做。

## 離線整合
- 單獨安裝：此套包含 `manifest.webmanifest` 與 `sw.js`，快取本目錄所需檔案。
- 入口網整包安裝：須將本單元實際複製到入口網自身的受控路徑（例如 `Bio-Class/units/sugar/`），並納入入口網離線預載清單；**僅放外部連結不足以保證離線**。
- `unit.json` 供未來入口網整合使用，並不是已經完成整包安裝。

## 教學注意
所有動態大小與粒子只是概念示意，不是血糖濃度與實際時間或速率的數據。正常運動不一定造成低血糖。
