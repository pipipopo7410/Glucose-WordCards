# 血糖調節 3.1.1（獨立安裝版）

這是沿用 3.1 的完整獨立部署版本。請將 ZIP **解壓後的檔案全部**上傳 GitHub Pages 專案根目錄（不能直接把 ZIP 當網站上傳）。

1. 先完成五條核心關係並按「檢查架構」。選做脂肪合成、細胞利用仍不影響通關。
2. 概念圖完成後，畫布右上會出現「🍚 吃飯」「🏃 運動」，若遮住字卡，系統會在可能情況下調整字卡位置。
3. 運動演示會在特定階段彈出腎上腺素，**平常不需放腎上腺素**。肝臟→血管僅需升糖素一格。
4. 演示可暫停、繼續、結束；任何動畫都不會修改已作答的物質或連線。
5. iPad：用 Safari 開啟 GitHub Pages 網址 → 分享 → 加入主畫面；Android Chrome 可透過選單安裝。

**科學模型限制**：糖原儲存與脂肪合成是可能同時發生的代謝過程；本動畫特意先聚焦糖原再展示脂肪，並非表示必須「完全裝滿」糖原庫後脂肪才能合成。運動警報代表假想的血糖過低情境，並非正常運動必然引起低血糖。物質卡面積僅示相對量，非實測濃度。

**部署安全**：這次只供 3.x 測試儲存庫更新，無需改動原有 1.0/2.0 網站。PWA 更新後請重新整理一次再測；iPad 真實手勢與飛航模式重啟仍需要實機驗收。
